IIW Dataset Schema

- Sequence length: T
- Frame rate: __ fps

- Key Joint Pose: [15(=Key Joints), 3]
	- Key joints from 25 Ybot character
	- Key joints = [0,1,3,4,6,8,9,13,15,16,17,20,22,23,24]

- Ordering of Body-Parts 
	- base/pelvis , spine, right hand, left hand, right foot, left foot
		
Per frame: elements of 135+3+6+60+540x3+540x10+6x540
1. Character Pose : 15 joints x 9 = data indicies[:135]
		- joint 별 9 ( positions, forward, up)
		- seen from floor orientation

2. Root velocity : 3 = data indices [135:135+3]
		- linear velocity from previous root's position to current root' position

3. Body-part contact label : 6 = data indices [135+3:135+3+6]
		- one-hot vector of body part is being contact or not

4. Human-Furntirue contact label : 6 x 10 = data indices [135+3+6:135+3+6+6x10] 
		- body part-level one-hot vector of furniture type with contacted.
		- ordering : ground, chair, desk, board, bed, null, base, spine, hand, foot

5. Ray hit points : 540 x 3 = data indices [135+3+6+60:135+3+6+60+540x3]
		- vertical samples : Rays x Samples  = 20 x 7 = 140
		- horizontal samples : Rays x Horizontal Samples = 20 x 20 = 400
		- non-hit samples : position is [10,10,10]

6. Sample-level furniture label : 
		- 540 x 10 = data indices [135+3+6+60+540x3:135+3+6+60+540x3 + 540x10]
		- ordering : Ground, chair, desk, board, bed, null, base, spine, hand, foot

7. IIW (Interaction Intensity Weight) :
		- !6 x 540! = data indices [135+3+6+60+540x3+540x10:135+3+6+60+540x3+540x10 + 6x540]
		- body part-level weights of samples
		- ordering : body part ordering
